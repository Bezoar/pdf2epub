# v1 implementation plan

**Status:** active · **Specs:** [main](../specs/main.md) and its satellites · **Parent ticket:** [v1 build (#20)](https://github.com/Bezoar/pdf2epub/issues/20) · **Decision:** [Plan and build-ticket format](https://github.com/Bezoar/pdf2epub/issues/16)

This plan is an index. It says in which order v1 is built, which ticket owns which acceptance criterion (AC), at which seams tests may be written, and which ticket creates which fixture. It restates no requirement: the [specs](../specs/main.md) are normative, and each ticket links back to the AC text it implements. How to write the code and tests is in [coding instructions](../instructions/coding.md); how work moves through PRs is in [GitHub instructions](../instructions/github.md).

Each slice is a vertical, tracer-bullet ticket under the parent ticket, with its blockers recorded as native GitHub dependencies. A ticket is done when every non-manual spec AC it owns has a marked, passing test ([TST-R17](../specs/testing.md#tst-r17)) and those IDs are gone from the pending-AC list ([TST-R20](../specs/testing.md#tst-r20)). **Manual** ACs are confirmed in [T26](#t26), and local ACs (ticket-only checks with no spec ID) are confirmed as their ticket describes.

### T6: Worker isolation, timeouts and interrupts

**Ticket:** [#28](https://github.com/Bezoar/pdf2epub/issues/28) · **Phase:** 2 · **Type:** AFK · **Blocked by:** [T5](#t5) ([#27](https://github.com/Bezoar/pdf2epub/issues/27))

In subprocess isolation (the default, and the CLI's only mode) each conversion runs in its own worker, so crashes and hangs cost one file and `--timeout` is enforced; in-process isolation gives the same results otherwise but no crash containment or timeout. Ctrl-C and cancellation behave as specified in both modes.

- **ACs:** [API-AC3](../specs/api.md#api-ac3), [API-AC4](../specs/api.md#api-ac4), [BAT-AC11](../specs/batch.md#bat-ac11), [BAT-AC12](../specs/batch.md#bat-ac12), [BAT-AC13](../specs/batch.md#bat-ac13), [BAT-AC14](../specs/batch.md#bat-ac14), [CLI-AC17](../specs/cli.md#cli-ac17)
- **Local ACs:** test hooks for worker crash, hang and slowness exist only in test builds
- **Seams:** [Python API + event sink](#seam-api), [CLI subprocess (`--json` and human output)](#seam-cli)
- **Creates:** none
- **Uses:** public-domain sample

### T15: Page labels and page sequence gaps
