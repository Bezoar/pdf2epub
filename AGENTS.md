# pdf2epub

pdf2epub converts PDF books (born-digital or scanned) into reflowable EPUB 3 books, one at a time or in batches, with a Python core and CLI.
It opens password-protected PDFs only with a password the user supplies, honours permission restrictions, and never circumvents DRM: see [Legal scope](docs/specs/main.md#legal-scope).
